OFFLINE BROWSER + NODE.JS 20+ CLI

Inspect, normalize, report.

Process 1–20 UTF-8 CSV files, up to 10 MiB each and 20 MiB combined. Each accepted source produces a comma-separated normalized CSV and an issue report; the browser bundles the outputs and manifest into one ZIP. The CLI also supports JSON output, distinct exit codes, and protection against overwriting existing output.

Generic structural checks and bounded Shopify and WooCommerce product profiles are included. Parsed data rows are preserved. Fatal input errors produce reports without partial normalized output.
