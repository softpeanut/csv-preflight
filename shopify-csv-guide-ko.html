SHOPIFY PRODUCT CSV PREFLIGHT

Shopify 상품 CSV,
가져오기 전에 볼 5가지

CSV가 열리는 것과 Shopify가 안전하게 받아들이는 것은 다릅니다. 아래 순서는 Shopify 공식 상품 CSV 문서를 2026-08-27에 다시 확인해 정리한 사전 점검 목록입니다.

먼저 백업하세요. Shopify는 시작된 상품 CSV 가져오기를 취소할 수 없고 과거 가져오기 내역도 별도 화면에서 제공하지 않는다고 안내합니다. 덮어쓰기 전에 상품 데이터를 내보내 보관하세요.

1. UTF-8과 쉼표 구분인지 확인

Shopify 상품 CSV의 열은 쉼표로 구분해야 하며 가져오기 파일은 UTF-8이어야 합니다. 세미콜론이나 탭으로 저장된 파일, UTF-16 파일은 스프레드시트에서 열려도 가져오기 단계에서 실패할 수 있습니다. 공식 문서는 상품 CSV가 15MB를 넘으면 작은 파일로 나누라고 안내합니다.

2. 새 상품과 업데이트의 필수 헤더를 구분

새 상품은 Title이 필수이고, 변형 상품을 추가한다면 URL handle도 필요합니다. 기존 상품 업데이트에는 정확한 Title과 URL handle 열이 필요합니다. 헤더의 철자와 대소문자를 현재 공식 표와 대조하세요.

3. 옵션 관련 열을 혼자 넣지 않기

SKU나 Weight value (grams)처럼 변형과 관련된 열을 업데이트한다면 대응하는 Option1 name과 Option1 value도 필요합니다. Shopify는 의존 열을 빼면 기본 변형이 새로 생기거나 기존 변형이 삭제될 수 있다고 경고합니다.

4. 닫히지 않은 따옴표와 행 너비 확인

쉼표나 줄바꿈을 포함한 필드는 큰따옴표로 감싸야 하고, 필드 안 큰따옴표는 두 번 써야 합니다. 닫히지 않은 따옴표, 헤더보다 열이 짧거나 긴 행, 중복 헤더는 가져오기 전에 먼저 보고 원본 의미를 확인하세요. 자동 도구가 부족한 값을 추정하거나 긴 행을 잘라내면 데이터 의미가 달라질 수 있습니다.

5. 작은 표본으로 먼저 검증

Shopify는 대규모 이전 작업을 수행하는 파트너에게 작은 변경 집합으로 먼저 시험하라고 안내합니다. 전체 덮어쓰기 전에 민감정보가 없는 소량 복사본으로 헤더, 변형, 이미지 URL과 결과를 확인하세요.

무료 검사기가 확인하는 범위

CSV Preflight의 Shopify 프로필은 쉼표, 현재 필수 헤더, 일부 문서화된 값과 열 의존성을 브라우저 안에서 검사합니다. 스토어에 접속하거나 이미지 URL을 가져오지 않으며 동적 Markets·메타필드 열, 구형 호환 헤더, 모든 업무 규칙을 판정하지 않습니다. 가져오기 성공 보장이 아니라 실수를 줄이는 사전 점검입니다.
